
# Tajný právník BDVH

Tato aplikace je interaktivní právní asistent zaměřený na kauzu BDVH (Bytové družstvo Větrná Hůrka).
Pomocí AI umožňuje analyzovat dokumenty, odpovídat na otázky a orientovat se v právní historii.

## Spuštění aplikace
```bash
streamlit run app.py
```

## Složky
- `app.py`: hlavní Streamlit aplikace
- `drive_utils.py`: pomocné funkce pro Google Drive API
- `.streamlit/secrets.toml`: přístupové klíče
- `requirements.txt`: knihovny
