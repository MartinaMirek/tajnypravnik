# Tajný právník BDVH

Tato aplikace je interaktivní právní asistent zaměřený na kauzu BDVH (Bytové družstvo Větrná Hůrka). Pomocí AI umožňuje analyzovat dokumenty, odpovídat na otázky a orientovat se v právní historii.

Spuštění aplikace: [Streamlit](https://streamlit.io)
